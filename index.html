ผู้ให้บริการ AI

เพิ่ม API key ใน Supabase Edge Function Secrets หรือระบบ Secret Manager ฝั่งเซิร์ฟเวอร์ ไม่กรอก key จริงในหน้านี้

หมายเหตุด้านโควตา: ระบบจะส่งต่อเมื่อ API ตอบกลับข้อผิดพลาดที่เหมาะสม เช่น rate limit หรือบริการขัดข้องเท่านั้น ไม่สามารถรับประกันว่าจะดึงคำตอบบางส่วนจากหน้าเว็บของ ChatGPT/Claude/Gemini ได้ และไม่ควรใช้หลายบัญชีเพื่อหลบข้อจำกัดหรือเงื่อนไขของผู้ให้บริการ
